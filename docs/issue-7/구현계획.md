## 4. 기술 메모

- **금 곡괭이 예외**: 금 곡괭이는 등급상 '나무'와 동급(철 이상 못 캠). 티어 표에 명시.
- **주입 우선순위**: responder 프롬프트에서 `[확정 규칙]`을 검색 본문보다 위에 배치하고 "충돌 시 우선" 명시.
- **결정적 테스트**: LLM 최종 문장이 아니라 **주입 단계(structured_facts 내용)**를 검증해 플레이키 방지. 라이브 챗은 수동 보조 검증.
- **best-effort**: 매칭 사실이 없으면 빈 리스트 → 기존 위키 기반 답변 그대로.

## 5. 검증 (end-to-end)

1. `uv run pytest tests/test_facts.py` → 단위·회귀 통과
2. `docker compose up -d mysql` + `bash start.sh` (Qdrant는 클라우드)
3. 라이브: `"철은 어떻게 캐?"` 5회 → **돌 곡괭이** 일관 / `"양털 어떻게 구해?"` → **철 주괴=제련** 정확 / `"다이아 어떻게 캐?"` → 철 곡괭이
4. 회귀 없음 확인: 기존 정상 응답("방금 시작했는데 뭐부터?") 그대로
